glslang's C interface headers as shipped in the LunarG Vulkan SDK 1.4.350.0 (Include/glslang/Include:
glslang_c_interface.h, glslang_c_shader_types.h, visibility.h; Include/glslang/Public/resource_limits_c.h),
unchanged. Headers only: the Vulkan renderer loads glslang.dll (and glslang-default-resource-limits.dll) from
the SDK's Bin at run time to compile shader programs the offline SPIR-V build doesn't have (stage 5.5).
